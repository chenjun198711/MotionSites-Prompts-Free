12.5 · SCROLL FILM ENGINE
  Native scroll sets a target; a rAF loop eases a displayed progress toward it
  (frame-rate independent), and that one value drives both the film's
  currentTime and every overlay. The film is fetched whole into a blob so seeks
  never wait on the network, and a new seek is only issued once the previous one
  has landed, so the decoder is never flooded.

  FILM_MAP (scroll progress → film progress, piecewise linear, both 0..1):
    [[0,0],[.12,.25],[.47,.52],[.72,.78],[.92,1],[1,1]]
    hero drift 0–2.5s | vision: rock turns toward camera 2.5–5.2s |
    dive through the foliage 5.2–7.8s | ground settles 7.8–10s

  Helpers:
    c01(x)       clamp 0..1
    ramp(p,a,b)  c01((p-a)/(b-a))
    out3(t)      1-(1-t)^3
    inOut(t)     t<.5 ? 4t³ : 1-((-2t+2)³)/2
    map(m,p)     piecewise-linear lookup over FILM_MAP
    live(el,on)  toggles .live only when the state actually changes

  render(p) — early-return if p === last. Then:
   01 hero lifts away over the first stretch of scroll:
      h = out3(ramp(p,0,.11));
      --ho = (1-h).toFixed(4);  --hy = (-56*h).toFixed(2)+'px';
      frame.dataset.hero = h>.995 ? 'off' : 'on';
   header steps aside during the dive, returns on the ground:
      bo = c01(1 - ramp(p,.12,.2) + ramp(p,.76,.84));
      --bo = bo.toFixed(4);  frame.dataset.bar = bo<.01 ? 'off' : 'on';
   02 vision — tag, masked lines, then sub; exits by pushing past camera:
      vin = ramp(p,.15,.31);  vout = inOut(ramp(p,.47,.57));
      live(vis, vin>0 && vout<1);
      vis.opacity = 1-vout;
      vis.transform = translate3d(0, -18*vout px, 0) scale(1 + .14*vout);
      tt = out3(ramp(vin,0,.4));
        tag opacity = tt; tag transform = translate3d(0, 10*(1-tt) px, 0);
      per line i: lt = out3(ramp(vin, .12+i*.13, .62+i*.13));
        line transform = translate3d(0, 110*(1-lt) %, 0);
      st2 = out3(ramp(vin,.6,1));
        p opacity = st2; p transform = translate3d(0, 12*(1-st2) px, 0);
      veilV.opacity = Math.min(vin, 1-vout);
   03 ecosystem — copy settles, then the pins acquire one by one:
      ein = ramp(p,.8,.95);  live(eco, ein>0);  eco.opacity = ein>0 ? 1 : 0;
      et = out3(ramp(ein,0,.55));
        eTop opacity = et; eTop transform = translate3d(0, 22*(1-et) px, 0);
      per spot j: s = out3(ramp(ein, .3+j*.12, .62+j*.12));
        spot opacity = s; spot transform = scale(.7 + .3*s);
      veilE.opacity = ein;
   portrait pan — portrait crops keep only a sliver of the 16:9 film, so as the
   dive lands, pan the framing left to keep the fern in shot:
      if (isFlow) { ox = baseX - (baseX-26)*inOut(ramp(p,.68,.9));
                    film.style.objectPosition = ox+'% '+baseY+'%'; }
      else if (film.style.objectPosition) film.style.objectPosition='';

  seek(p): if !ready return; wantT = map(FILM_MAP,p) * Math.max(0, dur-.05);
    if (film.seeking) return;   // never flood the decoder
    if (Math.abs(film.currentTime - wantT) > .0005) film.currentTime = wantT;

  rAF loop: readScroll() sets target from
    (pageYOffset || documentElement.scrollTop) / (scrollHeight - innerHeight);
    loop(now): dt = prev ? Math.min(64, now-prev) : 16.667;
      k = reduce ? 1 : 1 - Math.pow(1-.11, dt/16.667);
      // ~0.11 per 60Hz frame: heavy enough to glide, light enough to feel attached
      cur += (target-cur)*k;
      if (Math.abs(target-cur) < .00004) cur = target;
      render(cur); seek(cur);
      re-request while cur!==target || (ready && film.seeking), else prev=0.
    kick() = readScroll() + start rAF if not already running.
    Bind: scroll → kick (passive); resize → fit(), last=-1, kick() (passive);
          film 'seeked' → if still off target by >.0005, kick().

  Readiness: onReady() (idempotent) → ready=true; dur=film.duration||0;
    film.pause(); fit(); film.currentTime = map(FILM_MAP,cur)*Math.max(0,dur-.05);
    film.classList.add('on').
  film 'loadeddata' → iOS only paints a never-played video after a play(), so
    prime it muted: var pr=film.play(); pr&&pr.then ? pr.then(onReady,onReady) : onReady().
  Source loading: useSrc(u){film.src=u;film.load();}
    if (fetch && URL.createObjectURL) → fetch(FILM_SRC,{mode:'cors'})
        → r.ok ? r.blob() : throw → useSrc(URL.createObjectURL(blob)),
          on any failure → useSrc(FILM_ORIGINAL)
    else → useSrc(FILM_SRC)
  film 'error' → if current src isn't FILM_ORIGINAL, useSrc(FILM_ORIGINAL).
  Finally: readScroll(); cur = target; render(cur);
