## Structure

```
body
  section.hero (z-index 1, isolation: isolate, min-height 100dvh, overflow hidden)
    header.nav (absolute top, only on hero — never on section 2)
      a.logo → Horizon + span.accent X
      .nav-end
        nav.links → About (#about) / Careers / Impact / Contact
        .lang → EN dropdown (ES, FR, DE)
    .rocket-wrap → hidden <video.rocket-src> + <canvas.rocket>
    .hero-content → h1, tagline, CTA
  .cover (z-index 4, will-change: transform)   ← THIS is what parallax moves
    img.rocks (z-index 6)
    section.about#about (z-index 1, min-height 100dvh)
      .about-inner (z-index 2)
```

Do **not** put a tall spacer/seam between sections. Rocks live **inside `.cover`** with the about section so they scroll together over the hero.

**Chroma-key (required).** Video has a navy plate, not alpha. Each rAF:

1. Size canvas to CSS box.
2. `drawImage(video)`.
3. Per pixel vs key **`(R,G,B) = (1, 9, 31)`**:
   - `HARD = 22²`, `SOFT = 36²`
   - `dist ≤ HARD` → alpha `0`
   - `HARD < dist < SOFT` → alpha `((dist-HARD)/(SOFT-HARD))*255`
4. `putImageData`. Context: `{ alpha: true, willReadFrequently: true }`.

Do **not** rely on WebM alpha / ffmpeg colorkey — that failed. Do **not** skip `mix-blend-mode: lighten`.

## Rocks + parallax (critical)

`.rocks`: `position: absolute; left: 0; top: 0; z-index: 6; width: 100%; height: auto; pointer-events: none; transform: translateY(-50%);`

That `-50%` parks the belt on the **fold**, not over the about copy. Width **100%** — no 145–150vw, no horizontal parallax, no scale.

JS moves **`.cover` only** (rocks + about together over the hero):

```
vh = innerHeight
sEnd = vh * 0.55
s = clamp(scrollY, 0, sEnd)
extra = s * ((vh - sEnd) / sEnd)
cover.style.transform = `translate3d(0, ${-extra}px, 0)`
```

rAF-throttled scroll + resize. If `prefers-reduced-motion: reduce`: transform none, no cover motion.

Do **not** create a 90–180vh `.seam` gap. Hero `overflow: hidden` + `isolation: isolate` is a stacking context; rocks must be in `.cover` **above** the hero (`z-index: 4` vs hero `1`).

## Animations

**Hero `.reveal`:** start `opacity: 0; translateY(1.15rem)`; `animation: rise 0.9s cubic-bezier(0.16, 1, 0.3, 1) forwards`; delay `--d`.

Delays: h1 `0.12s`, tagline `0.28s`, CTA `0.44s`.

**About `.reveal`:** `animation: none`. Same opacity/translate start. Transition `0.9s` same easing, delay `--d`. Fire once when `.about-inner` gets `.is-in` via `IntersectionObserver { threshold: 0.22 }`, then disconnect.

About delays: `02` `0s`, h2 `0.1s`, rule `0.18s`, lead `0.26s`, cols `0.38s`, chips `0.5s`.

Reduced motion: all reveals instantly visible, no animation/transition.

Lang dropdown: toggle `hidden`, `aria-expanded`, select EN/ES/FR/DE, click-outside close.
