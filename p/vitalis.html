=====================================================================
7. JAVASCRIPT (vanilla, one IIFE with "use strict", at end of body)
=====================================================================
7a. REVEAL QUEUE — deliberately NOT IntersectionObserver.
Keep an array "pending" of elements to reveal. check() loops it backwards, and for each
element whose getBoundingClientRect() satisfies (top < innerHeight*0.92 && bottom > 0),
adds class "in" and splices it out.
- queue(): rAF-throttled via a "ticking" flag, AND ALSO schedules setTimeout(checkNow,120).
- checkNow(): resets ticking and calls check() synchronously.
- Bind queue() to window scroll (passive:true) and resize.
- Also run checkNow() on window load and at setTimeout 60ms, 500ms, 1600ms.
- LAST-RESORT POLL: setInterval(400ms) calling checkNow(), clearing itself when
  pending is empty. Rationale: in some embedded webviews/hidden tabs, scroll events,
  requestAnimationFrame AND IntersectionObserver can all be suppressed — content that
  starts at opacity:0 must never be able to stay invisible forever.

7b. WORDMARK: take the string "Vitalis", split into characters, and for each create a span
with textContent = char and style --d = (920 + i*70) + "ms", appended to #word.

7c. LINE SPLITTER splitLines(el) for every .js-lines element:
- Cache original markup once in el.dataset.text; read stagger origin from data-start.
- Walk the cached markup's child nodes into a token list of {word, className}, preserving
  the class of any wrapping element (so <span class="dim"> survives).
- Render each token as a bare probe span into el, then group tokens into lines by comparing
  each probe's offsetTop (new line when it differs from the previous by more than 3px).
- Rewrite el.innerHTML as, per line:
  <span class="ln" style="--d:(start + i*95)ms"><i>…words…</i></span>
  re-wrapping any classed token in its own <span class="…">.
- Return el.querySelectorAll(".ln") and add each to the reveal queue.
Call buildLines() on init; also queue all ".story .r, .stat__rule" elements.

7d. HERO ON LOAD: playHero() adds "in" to every ".hero .r" and to #word.
Run on window load, or immediately if document.readyState === "complete".

7e. REFLOW: rebuild() re-runs splitLines for all .js-lines — first recording which blocks
were already revealed, filtering .ln entries out of pending, then re-adding lines as either
shown (if the block was already visible) or watched. Trigger rebuild() from
document.fonts.ready (so line breaks match the real webfont) and on resize, but ONLY when
window.innerWidth actually changed, debounced 160ms.

7f. MENU LOGIC:
- openMenu(): store document.activeElement; add .open to menu; aria-hidden="false";
  add .is-open to burger; burger aria-expanded="true" and aria-label="Close menu";
  add body.nav-open; make menu links focusable; after 260ms focus the close button.
- closeMenu(): exact inverse, and restore focus to the previously focused element.
- setMenuFocusable(on): add/remove tabindex="-1" on every a/button inside the menu so
  hidden links leave the tab order. Call it with false on init.
- Burger click toggles; close button click closes; clicking any menu link closes.
- Escape key closes when open.
- Focus trap: on Tab keydown inside the menu, wrap focus between first and last a/button.
